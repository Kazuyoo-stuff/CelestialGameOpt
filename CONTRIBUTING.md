# Contributing

## Branches
- `main` — stable release
- `dev` — development; open PRs against this branch

## Building binaries
See `src/README.md`.

## PR Structure
- One PR per feature/fix
- Commit titles: `fix: ...` / `feat: ...` / `chore: ...`
- Include logs or test output if relevant

## Issues
Use the provided templates (.github/ISSUE_TEMPLATE/).
